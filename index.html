Code Automaton — an open-source coding agent for your terminal.

I built Code Automaton to run several AI coding sessions side by side in one terminal, with any OpenAI-compatible model. It is free and MIT-licensed.

What it does

A small, readable tool with the features I actually wanted day to day.

Several live sessions

Each streams on its own. Switch away while a long turn runs and the reply keeps arriving in the background.

Steer mid-turn

Type while the agent works and your message is folded into the running turn, typically between tool calls.

Screenshots

Attach an image with /image or the clipboard. Image messages go to a separate, configurable vision model.

Any OpenAI-compatible API

DeepSeek by default; set CODA_BASE_URL and CODA_MODEL for others.

Scrollback that holds

The session keeps its history: the mouse wheel or Shift+PgUp scrolls back through it, and the last frame stays in your terminal after you exit.

Small and readable

TypeScript, two runtime dependencies, five tools: read, write, edit, list, and shell.

Code Automaton

An agentic coding tool for the terminal. It runs against any OpenAI-compatible API — DeepSeek by default — and keeps several live sessions open at once. Switch to another session while a long turn runs and the reply keeps accumulating in the background; switch back and it is there.

Install from npm (opens in a new tab) Source on GitHub (opens in a new tab)

Install

npm install -g code-automaton
coda --version

The package is code-automaton; the command is coda. You supply an API key in CODA_API_KEY.

Session recall

Sessions are saved as JSON and reloaded the next time you start. A session names itself after its first message and can be renamed from the picker.

Images

Attach a screenshot with /image or the clipboard and the model can reason about it. Image messages route to a separate vision model, so a text-only setup keeps working.

Tools and commands

Read, write, and edit files, list directories, and run shell commands — a small, readable tool set. Slash commands cover /image, /paste, and /quit.

Why I built it

I wanted a terminal coding agent that worked the way I do: several conversations at once, nothing lost when I close the terminal, and the ability to redirect a task without waiting for it to finish. Building one myself was also the best way to learn how agent loops, tool calling, and terminal UIs actually work.
